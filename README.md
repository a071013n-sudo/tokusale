# 今日の特売くん

登録したスーパーの特売情報をチェックし、買い物リストと概算金額比較ができるPWAです。

## 構成

```
tokusale/
├─ index.html          … PWA本体(3タブ: 設定 / 本日の特売 / 買い物リスト)
├─ manifest.json        … PWAマニフェスト
├─ service-worker.js    … オフラインキャッシュ用
├─ icons/                … アイコン(192px/512px)
└─ gas/Code.gs           … チラシ取得用 GAS Web App のコード
```

## セットアップ手順

### 1. GAS(取得API)のデプロイ
1. https://script.google.com/ で新規プロジェクトを作成
2. `gas/Code.gs` の中身をまるごと貼り付け
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 実行するユーザー: 自分
   - アクセスできるユーザー: 全員
4. 発行された `https://script.google.com/macros/s/xxxx/exec` をコピー

### 2. PWA本体の公開
`index.html` / `manifest.json` / `service-worker.js` / `icons/` を
そのまま `せんせいの道具箱` の任意のフォルダにアップロードしてGitHub Pagesで公開してください
(すべて相対パス参照なので、フォルダごと配置すればそのまま動きます)。

### 3. アプリ側の設定
1. アプリを開き「設定」タブでGASのURLを貼り付けて保存
2. 「よく行くスーパーを検索して登録」で店舗を検索・登録
   - プリセットにない店舗は「自由入力で登録」から店舗名とチラシページの実URLを入力
   - チラシURLは店舗ごとに異なるため、実際にブラウザでチラシページを開いて確認したURLを使ってください

## 「本日の特売」の取得について(重要な制約)

スーパーのチラシサイトはサイトごとにHTML構造がまったく異なり、
JavaScriptで動的に描画されるサイトも多いため、
**「これを貼れば全店で自動的に正確に取れる」万能パーサーは存在しません。**

`Code.gs` は以下の2段構えです:
- `DOMAIN_PARSERS`: ドメインごとに専用の抽出ロジックを登録する場所(テンプレート付き)
- `genericParser`: 登録がないサイト向けの簡易フォールバック(価格表記の近くのテキストを商品名候補として拾う、精度は粗め)

実際に使うスーパーのチラシページを開いて「ページのソースを表示」でHTML構造を確認し、
`DOMAIN_PARSERS` にそのサイト専用の抽出ロジックを追加していくことで精度が上がります。
(この部分は、これまで作られていたOCR・スクレイピングパイプラインと同様の考え方で拡張できます)

## 買い物リストの価格比較ロジック

- チラシから追加した商品は、その店舗の価格が自動的に入ります
- 手入力した商品や他店の価格は、買い物リストの各商品を開いて手動入力できます
- 比較欄では「価格が判明している商品」だけで合計を計算し、
  判明件数が最も多い店舗の中から最安値の店舗に「おすすめ」タグを表示します
  (未入力の商品がある場合は概算である旨が表示されます)
